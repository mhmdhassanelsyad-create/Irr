طريقة 1 (بدون Android Studio) - من الموبايل أو الكمبيوتر:
1) اعمل حساب على github.com وأنشئ Repository جديد (Private أو Public).
2) ارفع كل محتويات هذا المجلد (بما فيه مجلد .github) على الـ Repository.
3) افتح تبويب Actions ثم Build APK وانتظر دقيقتين تقريباً.
4) نزّل ملف IRR-Calculator-APK من أسفل صفحة التشغيل، فك الضغط، وثبّت app-debug.apk.
   (فعّل "التثبيت من مصادر غير معروفة" لو الأندرويد طلب.)

طريقة 2: افتح المجلد في Android Studio ثم Build > Build APK(s).

تعديل الحسابات: ملف app/src/main/assets/index.html
